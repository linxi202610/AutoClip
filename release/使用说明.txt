AutoClip 1.0  ——  选中即复制 / 双击粘贴
==========================================================

单文件程序，36 KB，免安装、不依赖运行库、不联网、不采集任何内容。


一、怎么启动
----------------------------------------------------------
双击 AutoClip.exe。程序启动后没有主窗口，只在屏幕右下角托盘区
出现一个绿色对勾图标。

推荐做法：把这个 exe 放在自己常用的文件夹里（例如
D:\Tools\AutoClip\），再建一个桌面快捷方式。
设置存在同目录的 AutoClip.ini 里，随程序一起走。

想开机自启：右键托盘图标 → 勾选「Start with Windows」。


二、功能一：选中即复制
----------------------------------------------------------
用鼠标拖选一段文字、一张图片、一个表格单元格，松开鼠标后静置
200 毫秒（可在设置里改成 120/200/300/500/800 ms），程序自动
替你按一次 Ctrl+C。
  · 双击选中一个词，同样会复制
  · 松手后 200 ms 内又点击鼠标，本次动作取消，不会误触发
  · 支持文字、图片、富文本；程序本身不写剪贴板，由原程序
    正常写入，所以 Word/浏览器里的格式、图片都不会丢


三、功能二：双击自动粘贴
----------------------------------------------------------
在能输入的地方（Word、记事本、浏览器输入框、微信、搜索框……）
双击鼠标左键，程序自动按一次 Ctrl+V。


四、为什么有「智能模式」（重要，默认开启）
----------------------------------------------------------
Windows 里双击的原义就是「选中这个词」，和「双击粘贴」天生冲突，
只能二选一。智能模式的做法是把两种动作都保住：

  双击落在编辑器里的文字上 → 当成选词：只复制，绝不粘贴
  双击落在编辑器里的空白处 → 当成粘贴：先把你原来的剪贴板内容
                              原样还原，再粘贴，剪贴板不被污染

另外无论智能模式开关与否，下面这些位置一律不粘贴：
  · 桌面、图标视图（防止把文件改成「重命名」状态）
  · 托盘、任务栏
这两条是为了避免双击误伤系统。

如果你想让双击在任何地方都粘贴：右键托盘 → 取消勾选
「Smart mode」即可，此时双击一律粘贴。


五、选项
----------------------------------------------------------
右键托盘图标可以：
  Select to copy         开/关 功能一
  Paste on double-click  开/关 功能二
  Smart mode             开/关 智能模式
  Copy delay             复制延迟 120/200/300/500/800 ms
  Pause all features     临时全部停用（快捷 Ctrl+Alt+P）
  Start with Windows     开机自启
  Settings...            打开图形设置面板（快捷 Ctrl+Alt+O）
  Help / Exit            说明 / 退出

托盘图标颜色：
  绿色   两个功能都开着
  琥珀色 只开了一个
  灰色   全关或已暂停

左键单击托盘图标 = 打开设置面板（就是你要的「选项界面」）


六、剪贴板安全
----------------------------------------------------------
· 程序不主动往剪贴板写「复制结果」，复制永远由原程序完成，
  所以格式、图片、多格式剪贴板都不会被破坏。
· 只有一种情况会写剪贴板：智能模式下双击后探测到「没选中任何
  东西」，此时它把你操作前的纯文本剪贴板原样写回去，再粘贴。
  如果操作前剪贴板里是图片，则不做任何写操作，只粘贴。


七、可能不灵的情况
----------------------------------------------------------
1. 目标程序以管理员身份运行时，Windows 不允许普通程序往里送
   按键。解决办法：AutoClip 也用管理员身份运行。
2. 全屏独占的游戏、部分远程桌面窗口、UAC 提权弹窗不响应模拟按键。
3. 安全软件拦截「全局鼠标钩子」时功能会失效（本程序只装鼠标
   钩子，不装键盘钩子，不记录、不上传任何内容）。
4. 有些程序（如某些 IDE）会自己接管 Ctrl+C 的复制行为，若目标
   程序不支持标准 Ctrl+C，则复制不到内容。


八、排查问题
----------------------------------------------------------
用 AutoClip.exe --debug 启动，会在同目录生成 AutoClip.log，
里面记录了每次手势识别、复制、粘贴的判定过程，可用来定位问题。
（--debug 还会顺便打开设置面板。）


九、文件说明
----------------------------------------------------------
AutoClip.exe     主程序（单文件，内含图标）
AutoClip.ico     图标文件，建快捷方式时可选用
AutoClip.ini     首次运行后生成，保存你的开关设置
AutoClip.log     仅 --debug 模式生成


十、卸载
----------------------------------------------------------
右键托盘 → Exit 退出；勾掉「Start with Windows」；
删除 exe、ico、ini 三个文件即可，注册表无需清理
（程序只在 HKCU\...\Run 下写过自启项，取消勾选会自动删掉）。
